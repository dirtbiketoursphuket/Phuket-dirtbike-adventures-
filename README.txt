Phuket Dirtbike Adventure — Website

FILES TO UPLOAD TO YOUR NEW GITHUB REPOSITORY:

- index.html          (the website)
- tour-video.mp4      (the video)
- photo1.jpg to photo13.jpg

HOW TO GO LIVE:

1. Create a new public repository on GitHub
   (example name: phuket-dirtbike-adventure)

2. Upload ALL the files above into the root of the repository
   (do not put them inside a folder)

3. Go to Settings → Pages
   - Source: Deploy from a branch
   - Branch: main
   - Folder: / (root)
   - Save

4. Wait 1–2 minutes, then open the link GitHub shows you.
